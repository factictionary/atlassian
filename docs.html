Smart Checklist & Definition of Done (DoD)

Official User Guide & Documentation • Published by Factictionary
Zero Configuration Required: Smart Checklist runs natively in Atlassian Cloud. As soon as you install it, the checklist panel is immediately available on all Jira issues.

1. Getting Started

To use the checklist on any Jira ticket:

  1. Open any Jira Software or Jira Service Management issue.
  2. Look at the issue details panel (or click the Apps dropdown).
  3. Click on Smart Checklist & DoD to open the panel.

2. Using Pre-Built Templates

Standardize acceptance criteria across your team in one click:

  • Click Templates in the toolbar.
  • Select one of the built-in templates:
    • Definition of Done (DoD): Acceptance verification, unit testing, code review, docs, and staging smoke test.
    • QA & Regression Testing: Repro step validation, cross-browser, edge case, and regression suites.
    • Release & Deployment Readiness: Database migrations, environment secrets, and monitoring alerts.
    • Security & Privacy Review: Auth checks, PII protection, input sanitization, and CVE scans.
  • Click Apply to populate the criteria instantly.

3. Definition of Done (DoD) Enforcement

Items flagged with Mandatory DoD enforce quality standards before tickets resolve:

  • When adding or importing items, check the Mandatory DoD box.
  • The app monitors the ticket and shows an alert banner if mandatory criteria remain unchecked.
  • Aligned with your organization's configured Jira workflow statuses.

4. Markdown Import & Export

Easily sync task lists with Git repositories, pull requests, and team chat:

  • Click Import / Export.
  • Paste any Markdown checklist (e.g. - [ ] My task or - [ ] [DoD] Mandatory criteria).
  • Click Import into Checklist to convert them to interactive checkboxes.
  • Click Copy Current as Markdown to copy all items to your clipboard.
